# Naomi Roadmap

This document outlines current development priorities, planned features, and long-term research directions for Naomi.

---

## ✦ Now (Current Release v0.1.0)
- [x] **Local Speech Capture:** One-tap voice capture with live audio waveform and real-time transcription.
- [x] **Intelligence Pipeline:** Automatic title generation, topic detection, subtopic hierarchy, task extraction, idea detection, and decision logging.
- [x] **Stitch UI Design System:** Minimalist, typography-first interface with adaptive Dark / Light / System theme persistence.
- [x] **Ambient Mode:** Continuous listening session manager with foreground service and chunked processing.
- [x] **Knowledge Graph & Tree:** Dynamic hierarchical topic tree with real-time memory count.
- [x] **Search & Filters:** Instant on-device search across memories, topics, and tasks.
- [x] **Actionable Tasks:** Extracted task checklist with due date detection and strike-through state toggle.
- [x] **Home Screen Widget:** Signature Naomi Orb quick-capture widget with dynamic glance previews.
- [x] **Privacy & Storage:** Configurable audio retention policies and Markdown export.

---

## ✦ Next (Upcoming v0.2.0)
- [ ] **On-Device Small LLM Integration:** Optional Gemma 2B / ONNX / Whisper.cpp local inference pipeline for complex conversational summaries.
- [ ] **Bi-directional Knowledge Linking:** Automatic cross-referencing and backlinks between related memories across different topics.
- [ ] **Interactive Widget Quick Actions:** Expandable widget sheet for toggling pending tasks directly from the home screen.
- [ ] **Offline Vector Search:** Local embedding generation for semantic search beyond keyword matching.
- [ ] **Custom Topic Rules:** User-defined categorization rules and aliases for specific projects.

---

## ✦ Later
- [ ] **End-to-End Encrypted Sync:** Optional peer-to-peer or self-hosted encrypted sync (e.g. via Syncthing / WebDAV).
- [ ] **Audio Playback Timeline:** Optional attached voice snippet playback for reviewing original recording nuances.
- [ ] **Wear OS Companion:** Naomi Orb quick-record tile for Android smartwatches.
- [ ] **Multi-language Topic Classification:** Expanded language models for multilingual memory organization.

---

## ✦ Ideas & Research
- Proactive memory surface: Contextual memory resurfacing based on time of day or calendar events.
- Canvas knowledge view: Interactive graph visualization of connected topics and idea clusters.
